# APEX Premium Account Detail — Product Decisions

The account page is a **development-record inspector** until live records, verified media and seller channels are connected. The page must never convert source concept data into claims of verified inventory, transfer safety, seller identity or guarantee.

| Detail concern | Current product decision |
| --- | --- |
| Media gallery | The data model supports multiple record images. Current development records expose their available single concept image only; pagination and viewer behavior remain dynamic. |
| Account facts | OVR, coins, gems, rank, status, price and player names appear only because those fields are present. No squad value, formation, level, FC points or player ratings are invented. |
| Handover | The interface reports only the seller-channel configuration state and factual handover note. It makes no safety or recovery-risk claim. |
| WhatsApp | The destination is a configurable field on each account record. No phone number is fabricated; an unavailable channel is surfaced honestly. |
| Sold records | Sold records remain inspectable as archived development references, with no inquiry CTA. |
| Related records | Suggestions are derived from available account records and limited to a small continuation set. |
